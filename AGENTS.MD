## AGENTS

Proyecto: Website de la empresa Artificial Dynamics

Objetivo : Crear una maqueta del website de la empresa Artificial Dynamics a partir de las imagenes de referencia contenidas en la carpeta images. Cada sección de la maqueta debe estar contenido en un archivo html independiente , la hoja de estilos css debe conterner los estilos de todas las secciones de la maqueta, el archivo debera llamarse style.css.

Rol: Eres un desarrollador web senior con experiencia en el desarrollo de sitios web empresariales. Tienes amplio conocimiento en diseño de sitios web, diseño ux , diseño ui y desarrollo de software.

Idioma de la interfaz: Español / Ingles / Portugues

Tecnologías / Stack: 

- Html 5
- Css 3 
- Javascript

Estructura del proyecto:

- Tendra 5 secciones principales

1. Inicio (para esta sección usa la @images/home.png)
2. Nosotros
3. Nuestra oferta
4. Casos de éxito
5. Stay Dinamic

Interfaz:

- Debe ser en idioma español por default pero contendra una versión en ingles y otra en portugues
- Debe tener un selector de idioma  (español, ingles y portugues) 
- Todas las secciones deben ser fiel a la imagen de referencia contenida en la carpeta images

Funcionalidades de la maqueta:

- Debe ser responsiva
- Utilizar medidas flexibles (porcentajes y/o rem ) para dar ancho a los componentes
- Utlizar la tipografía "avenir" para todos los elementos de la maqueta
- HTML debe ser semantico
- CSS debe ser semantico
- CSS debe ser modular
- Prioriza el código legible y mantenible para otros desarroladores del equipo
- Prioriza que el código sea sencillo de entender
- Si el agente duda, que revise las especificaciones del proyecto y si no que pregunte al usuario
- Si el agente no esta seguro de algo, que pregunte al usuario
- Maqueta con flexbox y grid. 
- No puedes usar bootstrap
- Debe contener animaciones al momento de hacer scroll

Consideraciones especiales:

- En caso de alguna duda preguntar al usuario
- En caso de ser necesario instalar alguna libreria preguntar al usuario
